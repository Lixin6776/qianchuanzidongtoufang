千川直播运营 Agent · 项目全流程图

确定性数据管线 + Reflection 审查修订 + 操作结果反馈学习

采集校验实时分析运营分析Reflection输出结果学习
数据源只读接入本机 Chrome CDP 或开放平台 API；不直接修改账户。
01

数据采集

5 MIN / EVENT
直播大屏消耗 / GMV / ROIGPM / CPM / 在线素材明细千川操作日志直播场次
5 分钟循环直播进行中，持续读取并生成新快照；直播结束后停止轮询。
02

数据可信校验

HARD GATE
完整性ROI = GMV / 消耗漏斗不倒挂基础 + 追投对账数值合理区间口径区分
校验失败停止下结论和调建议；只输出原始读数、缺失项和需要人工核对的位置。
实时报表状态卡、聊天摘要、5 分钟盯盘报表；默认精简，详情按需展开。
03

直播实时分析

LIVE WATCH
综合营销 ROI目标差距GPM / CPM近5分钟消耗在线人数问题 → 依据 → 归因
直播结束立即停止盯盘轮询；生成终场复盘，而不是继续刷新上一场数据。
素材动作分档跑量达标、跑量不达标、高点击低转化、高效低量；每条素材看消耗、ROI、点击率和转化率。
04

运营结构分析

DELIVERY + MATERIAL + OPS
基础 vs 追投追投占比素材集中度高消耗低效素材操作上下文10/20 分钟结果
场次复盘本场概况、漏斗、投放结构、问题、方案、下场准备、历史对照全部落盘。
确定性护栏数据计算和只读边界不交给大模型；Reflection 只改写分析文本。
05

Reflection 审查修订

MAX 1 REVISION
Draft 初稿基于当前上下文生成结论和方案
Critic 审查数字依据 / 因果 / 口径 / 可执行性 / 只读
Revise 修订有问题才改；不得补猜缺失数据
Final 校验格式、非空、失败回退初稿
何时触发分析与建议使用 Reflection；简单问题、错误信息和确定性计算不重复反思。
输出原则数据准确优先于分析；没读到就写“没读到”；每个动作必须有成功标准和止损条件。
06

运营输出

OPERATOR VIEW
实时状态卡聊天报表摘要直播复盘素材分析运营助手对话飞书通知
人工确认预算、出价、计划和素材调整只生成建议，必须人工确认后执行。
反馈回流操作结果进入下一轮同场景判断；只统计单一操作，扣掉基线漂移。
07

数据资产与学习

OUTCOME FEEDBACK
操作事件窗口 ROI净效应流速分层n ≥ 20观察性相关，不是因果
决策场景流速偏低 / 正常 / 加快分别积累操作效果，下次遇到同场景优先调用历史结论。
↺
完整闭环：操作 → 10/20 分钟结果 → 扣基线漂移 → 场景分层 → 样本护栏 → 更新建议 → 下一次决策数据越多，系统不是“越来越会说”，而是同一场景下的判断越来越可校准。

# 运营模式

## 只读运营模式

- 只读取数据和生成分析
- `hard_constraints.read_only=true`
- `allowed_actions=[]`
- 预算、出价、计划和素材操作全部被阻断

## 全自动化投放模式

定义：Agent 可以自动生成投放任务和操作预览，但任何账户写操作必须由操作人员明确确认。

- `hard_constraints.read_only=false`
- `hard_constraints.automation_mode=confirm_required`
- `allowed_actions` 仅开放允许的动作
- 自动生成操作预览
- 必须经过确认流程
- 不允许绕过人工确认直接执行

当前开放的动作：

- 暂停 / 启用计划
- 修改计划预算
- 新建 / 复制 / 编辑计划
- 修改出价、定向和排期
- 绑定 / 解绑已有素材

默认不开放：

- 删除计划
## 模式切换

切换模式会创建新的策略版本：

1. 读取当前激活策略
2. 保留业务方向、主目标、预算和监控配置
3. 更新 `read_only`、`automation_mode` 和 `allowed_actions`
4. 创建并激活新版本

所有模式切换和动作执行均保留策略版本记录，方便追溯。
